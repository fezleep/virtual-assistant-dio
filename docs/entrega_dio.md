# entrega dio

desenvolvi um assistente virtual simples em python para praticar conceitos de text to speech, speech to text e automações básicas.

o projeto usa `gtts` para transformar texto em áudio e gerar um arquivo `output.mp3`. também possui uma função opcional com `SpeechRecognition` para tentar transformar fala em texto, dependendo do microfone e do ambiente local.

o assistente funciona principalmente em modo texto, então pode ser testado mesmo sem microfone. ele interpreta comandos simples como abrir o youtube, pesquisar termos na wikipedia, informar o horário atual e simular a busca por uma farmácia próxima abrindo uma pesquisa no navegador.

também criei um notebook para google colab com exemplos de text to speech, simulação de comandos por texto, pesquisa na wikipedia e abertura de links.
